# Contributing

This repository is a professional Community Operations portfolio and operating library.

## Contribution principles
- Add practical, reusable community-management assets.
- Prefer clear operating systems over generic advice.
- Use measurable definitions and decision-ready templates.
- Keep examples truthful and clearly labeled.
- Do not add fake historical screenshots, fabricated metrics or invented partnerships.

## Suggested contribution areas
- Community strategy
- Onboarding and retention
- Campaign operations
- KOL and partnership systems
- AMA/live programming
- Moderation and trust
- Analytics/reporting
- Case-study documentation

## Pull request expectations
A PR should explain:
1. What problem the asset solves
2. Who would use it
3. What changed
4. How success could be measured
