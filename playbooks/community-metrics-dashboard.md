# Community Metrics Dashboard Framework

> Portfolio framework for turning community activity into decision-ready reporting.

## Executive view
A useful report should answer:
1. Is the community growing?
2. Are new members activating?
3. Are existing members staying active?
4. What is driving engagement?
5. What problems are recurring?
6. What should we do next?

## Dashboard categories

### Growth
- New members
- Source of acquisition
- Organic vs campaign-driven growth
- Referral contribution

### Activation
- New-member first action
- Onboarding completion
- Event / campaign participation

### Engagement
- Active members
- Messages / conversations
- Contributors
- Event attendance
- Content interactions

### Retention
- Returning members
- Inactive cohorts
- Reactivation rate

### Operations
- Support volume
- Response time
- Escalations
- Moderation incidents
- Recurring product issues

### Sentiment
- Positive / neutral / negative themes
- Common requests
- Top friction points

## Weekly reporting structure
| Section | Output |
|---|---|
| Wins | What improved |
| Risks | What worsened |
| Insights | What members are telling us |
| Actions | What the team should do next |
| Owners | Who is responsible |
| Deadline | When it should happen |

The dashboard should drive decisions, not just display numbers.
