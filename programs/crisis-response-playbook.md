# Community Crisis Response Playbook

## First principle
Respond quickly, but do not guess.

## Severity
### Level 1 — Confusion / misinformation
Clarify facts and pin correct information.

### Level 2 — Widespread complaints
Acknowledge impact, centralize updates and create an escalation owner.

### Level 3 — Security / scam / account compromise
Lock down risky surfaces, warn members, collect evidence and escalate immediately.

### Level 4 — Legal / safety / major reputational incident
Escalate to leadership/legal/security before making unsupported public claims.

## Response flow
**Verify → Contain → Acknowledge → Update → Resolve → Review**

## Communication rules
- State what is known
- State what is not yet known
- Give the next update point
- Avoid blame/speculation
- Keep one source of truth
- Preserve evidence

## Post-incident review
Timeline, impact, root cause, response quality, member feedback and prevention actions.
