# AMA Guest Brief

## Session objective
Define the one outcome the audience should leave with.

## Guest context
- Name / role
- Expertise
- Relevant links
- Topics to avoid
- Recent work worth mentioning

## Host question flow
1. Warm-up / context
2. Core expertise
3. Practical examples
4. Community-specific questions
5. Audience Q&A
6. Closing takeaway
7. CTA

## Production checklist
- Confirm date/time
- Confirm platform
- Test audio/video
- Prepare backup questions
- Assign moderator
- Collect community questions
- Publish reminders
- Prepare recap owner

## Success metrics
Attendance, watch time, questions, engagement, sentiment, CTA completion and post-event content performance.
