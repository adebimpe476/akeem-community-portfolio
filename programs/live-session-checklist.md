# Live Session Checklist

## 24–48 hours before
- Confirm speakers
- Finalize run of show
- Publish reminder
- Brief moderators
- Prepare links/resources
- Test stream or room

## 30 minutes before
- Re-test audio/video
- Open moderator backchannel
- Pin session information
- Review escalation rules

## During
- Welcome and set expectations
- Introduce speakers
- Keep time
- Watch audience questions
- Moderate respectfully
- Repeat CTA clearly
- Capture key quotes/moments

## After
- Thank speakers
- Post recap
- Share recording/clips
- Answer unresolved questions
- Capture metrics and lessons
