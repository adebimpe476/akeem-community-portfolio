# Community Health Scorecard

Score each area from 1–5, then track movement over time.

| Dimension | Weight | Score | Notes |
|---|---:|---:|---|
| Growth quality | 15% | | |
| New-member activation | 15% | | |
| Engagement depth | 15% | | |
| Retention | 20% | | |
| Member sentiment | 10% | | |
| Moderation health | 10% | | |
| Contributor activity | 10% | | |
| Feedback responsiveness | 5% | | |

## Interpretation
- **4.3–5.0:** Strong and scalable
- **3.5–4.2:** Healthy with targeted improvements
- **2.5–3.4:** At risk
- **Below 2.5:** Requires intervention

## Review cadence
Track weekly; review trends monthly. A single score matters less than whether the community is improving or deteriorating.
