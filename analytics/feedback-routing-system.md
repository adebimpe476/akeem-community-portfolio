# Community Feedback Routing System

## Goal
Turn conversations into usable organizational intelligence.

## Intake categories
- Product
- Support
- Education/content
- Community experience
- Partnerships
- Bugs
- Safety/moderation
- Pricing/offer
- Feature request

## Workflow
**Capture → Tag → Validate → Prioritize → Route → Respond → Close loop**

## Priority
### P1
Security, safety, outage or widespread blocker.

### P2
High-frequency issue affecting core experience.

### P3
Useful improvement request or recurring friction.

### P4
Individual preference / low-frequency suggestion.

## Close-the-loop rule
When feedback results in a change, tell the community. Visible responsiveness builds trust and encourages higher-quality feedback.
