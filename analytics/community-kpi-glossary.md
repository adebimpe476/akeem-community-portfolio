# Community KPI Glossary

| KPI | Definition |
|---|---|
| New members | Members joining during the period |
| Active members | Members completing a meaningful community action |
| Activation rate | New members completing a defined first meaningful action |
| Retention rate | Members remaining active across defined periods |
| Reactivation rate | Inactive members returning to meaningful activity |
| Participation rate | Eligible members joining a campaign/event/program |
| Response time | Time to first useful response |
| Resolution rate | Support/moderation issues resolved |
| Referral rate | New members attributable to existing members |
| Contributor output | Approved contributions from structured contributor programs |
| Sentiment | Direction of member feedback and conversation tone |
| Advocacy | Members voluntarily amplifying, referring or defending community value |

## Rule
Define each KPI before reporting it. A dashboard is useless if teams interpret the same number differently.
