# Contributor Program Framework

A system for turning community participation into repeatable, visible contribution.

## Contribution types
- Moderation
- Reporting
- Content
- Education
- Testing
- Referrals
- Events
- Research
- Local/community support

## Contributor lifecycle
**Discover → Qualify → Onboard → Assign → Support → Review → Recognize → Advance**

## Contribution brief
Every task should include:
- Objective
- Deliverable
- Deadline
- Quality standard
- Owner
- Support contact
- Recognition/reward
- Measurement criteria

## Quality controls
- Submission checklist
- Reviewer assignment
- Clear approval criteria
- Feedback loop
- Repeat-contributor tracking
