# 30 / 60 / 90-Day Community Manager Plan

## Days 1–30 — Diagnose
- Audit channels, roles and community health
- Review onboarding and moderation systems
- Map top member segments
- Identify recurring questions and friction
- Establish baseline metrics
- Meet product, growth, support and leadership stakeholders
- Deliver quick wins

**Output:** community audit + prioritized action plan

## Days 31–60 — Build
- Improve onboarding
- Launch recurring programming
- Introduce reporting cadence
- Build KOL/partner pipeline
- Create contributor/ambassador structure
- Improve escalation and feedback loops

**Output:** operating system + first measurable programs

## Days 61–90 — Scale
- Optimize retention and reactivation
- Expand partnerships/KOL programs
- Standardize campaign playbooks
- Improve dashboards
- Document repeatable workflows
- Propose next-quarter roadmap

**Output:** scalable community roadmap with measurable goals
