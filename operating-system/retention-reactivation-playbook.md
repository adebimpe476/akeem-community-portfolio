# Retention & Reactivation Playbook

## Retention principle
Members stay when the community repeatedly delivers **utility, identity, progress or belonging**.

## Retention levers
- Useful recurring programming
- Recognition
- Peer connection
- Exclusive access
- Education
- Contribution opportunities
- Feedback acknowledgment
- Clear progress/status systems

## Inactivity cohorts
| Cohort | Signal | Response |
|---|---|---|
| New but inactive | Joined, no first action | Simplify onboarding |
| Previously active | Activity drops sharply | Personalized reactivation |
| Event-only | Joins only for rewards/events | Introduce deeper utility |
| Contributor fatigue | Output falls after high activity | Recognition + workload reset |

## Reactivation sequence
1. Identify inactive cohort
2. Diagnose likely reason
3. Send relevant message
4. Offer one easy re-entry action
5. Track return behavior
6. Capture reason for inactivity

## Metrics
- 7/30-day retention
- Reactivation rate
- Returning active members
- Churn reasons
